# Glossary

Dossier: folder grouping automation workflows, shown as "projet" in the UI. Rejected: "project", already the construction project of the ERP.
Run number: sequential number of a run within its organization, shown as #N.
Dry run: execution of the current graph where each connector answers with its sample output and nothing leaves the process.
Item: one element of the list a node receives or produces.
Deal: sales opportunity of a customer, shown as "opportunité" in the UI. Rejected: "lead", a prospect rather than an opportunity.
Expense: company cost recorded in the treasury journal, shown as "dépense". Not a supplier invoice.
Credit note: invoice of kind CREDIT_NOTE, shown as "avoir", numbered in its own AV series.
Series: numbering sequence per organization, kind (quote, invoice, credit note) and year.
